## Tecnologia para resolver problemas reais

A **Zosma Labs** desenvolve software independente, plugins e ferramentas para tornar fluxos de trabalho mais simples, rápidos e confiáveis. Criamos soluções para produção, apresentações, mídia e outros contextos em que uma boa ferramenta pode eliminar etapas e deixar a tecnologia trabalhar a favor das pessoas.

### Multitrack Tools

> **Produto comercial da Zosma Labs**

Uma central de controle para **REAPER** voltada a playback ao vivo: setlists, regiões, loops, pads, click, alteração de tom, cifras, projeção, automações, MIDI e controle web em uma única ferramenta.

**Windows · macOS · Linux** · Licença vitalícia · Atualizações incluídas
